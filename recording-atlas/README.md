# Атлас анализа записи ЭЭГ

Локальный профиль BrainVision, матрицы публикаций и подготовка плана через DeepSeek Harness.

- `corpus-index.csv` содержит 3 114 идентификаторов корпуса, статус локального текста и ссылки на PubMed и PMC.
- `pubmed-search.json` содержит запросы от 16.11.2026 и числа по поиску и загрузке.
- `Загрузка корпуса/` содержит скрипты получения источников.
- `Матрицы корпуса/` содержит словарь алиасов и скрипт построения матриц.
- HTML содержит код интерфейса и библиографические данные. Для наполнения поискового индекса используются локальные полные тексты и рабочие данные матриц.

Локальный запуск: установите зависимости из `requirements-local.txt` и запустите `local_atlas.py`. Внешняя авторизация Harness выполняется в пользовательском окружении. Исходные записи ЭЭГ и сессии Harness хранятся локально.
